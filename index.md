# 🎓 ToDL Course

**Theory of Deep Learning for Undergraduates** — a complete, self-paced curriculum that takes fresh BSc students with zero ML background to the research frontier.

## What this course is

| | |
|---|---|
| 🎯 **Audience** | Fresh BSc students, zero background required |
| 📚 **Content** | 6 books × 40+ papers, woven into one path |
| ⏱ **Format** | 74 two-hour sessions, tablet-first teaching |
| 🔬 **Outcome** | Research-ready: every module ends in a reproduction workshop |
| ⚖️ **Pace** | Precision over speed — module-based mastery, no rushing |

## Why it exists

1. **No reference textbook exists for deep-learning theory.** Classic ML books stop at SVM-era foundations. This course builds a spine from Arora's *Theory of Deep Learning* + Ye's *Geometry of Deep Learning*, with Vershynin / Shalev-Shwartz & Ben-David / Mohri / Sra–Nowozin as the foundation layers.
2. **Modern phenomena, rigorous treatment** — benign overfitting, NTK, neural collapse, score-based diffusion, scaling laws — taught from the original papers.
3. **Research-ready graduates.** Every module has a reproduction workshop; every capstone team leaves with an open problem that has no answer in the literature.
