# Course notes

> **Handwritten tablet notes** from each session will be added here as the course runs — one PDF per session, posted after each class.

## How it works

- Each session ends with a **one-page summary** written live on the tablet (the *"page of the day"*: definitions, theorem, open question).
- After class, the page is exported to PDF and uploaded here, linked in the table below.
- Notes accumulate over time — by the end of the course this page becomes the students' full archive.
