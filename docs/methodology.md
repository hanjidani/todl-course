# Methodology — sessions, tablet teaching, rules

## The fixed 2-hour session template

| Time | Part | What happens |
|---|---|---|
| 0–10 | **Warm-up** | 2–3 short questions from the previous session; each student solves on their own tablet, one reads aloud |
| 10–45 | **Intuition, pen-first** | New concept: start from a question and an example, then the definition — written live (teacher + students) |
| 45–50 | Break | |
| 50–75 | **Math with the pen** | Definition/theorem, step-by-step proof; before every step: "why is this step allowed?" |
| 75–105 | **Live exercise** | 1–2 small problems the students solve themselves (teacher only guides) |
| 105–110 | **3-line summary** | What we learned + the open question that seeds the next session |
| 110–120 | Q&A + homework | Homework: rewrite the session's pages from memory (eyes closed) + 2 examples |

Timing guards: intuition never exceeds 60 min total; off-path questions go to the "chocolate box" (written down, answered at term end).

## Tablet-first teaching (why pen beats slides)

1. **One concept = one page.** The single most important rule — slides cannot do this.
2. **Fixed color code:** black = definitions · blue = theorems/formulas · red = caveats/common mistakes · green = examples.
3. **Question before formula.** No formula is written unless the students have first answered "why do we need it?".
4. **Proofs are dialogues.** Each proof line is written only after asking "why is this step valid?".
5. **Students write alongside** — if someone is not writing, stop.
6. **Slides are only for figures/demos/code.** All definitions and theorems go through the pen.
7. **Persistence:** every session produces a summary page → exported to PDF → archived for the whole group.

## Sequence rules

1. The [session sequence](session-sequence.md) is a **prerequisite chain** — no jumping ahead (e.g., kernels 41–42 before NTK 43–44 is mandatory).
2. 🗣 seminar papers are assigned **2 weeks ahead** (15–20 min + 10 min discussion each, several students per session).
3. 📖 readings are checked via a **3-question checklist**, not reports.
4. Every module ends with a **student-taught review session**; the module summary page is archived.
5. If a group falls behind: cut 🔬/🗣 sessions, never the 🎓 core.

## Pacing

Module-based, not hour-based — pass the mastery criterion ([course map](course-map.md)), then move on.
Rough estimate: ~2.5 terms at 2 sessions/week. There is no rush; precision is the goal.
